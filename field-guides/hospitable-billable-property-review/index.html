Review Hospitable Billable Properties and Subscription Scope

AI-assisted editorial guide · Published November 20, 2026

Hospitable’s official billing documentation distinguishes a base subscription from active-property and other add-on charges. A host should model the actual account configuration before comparing a headline price with another product. This is a document-based buying guide, not a hands-on product test. Confirm the plan, currency and terms shown for your account before purchasing.

Decision processChecklistOfficial sources

Define the portfolio being billed

List physical properties and the channel listings attached to each. Identify parent-child arrangements, temporarily inactive properties and listings that represent the same place. Hospitable’s billing guidance explains how merged listings affect the count. Do not assume the number of channel advertisements equals the number of billable properties, or merge unrelated listings merely to reduce a count.

Separate the recurring base from usage

Record the selected plan and its included property allowance. The current documentation says paid-plan base charges continue while the subscription remains active, including when properties are inactive. Check the applicable pause or cancellation process separately. A quiet month is not automatically a zero-cost month simply because no guests arrive.

Identify additional components

Review the add-ons relevant to the proposed setup, such as devices or other features described in the current plan documentation. Mark which are included and which require separate charges. Do not treat a feature shown on a general marketing page as included in every subscription. Ask support to clarify account-specific or legacy-plan differences.

Build two realistic operating cases

Prepare an ordinary-month configuration and a seasonal or temporary-pause configuration. Use the vendor’s current calculator and a written confirmation where needed. Keep the property count, selected plan and enabled add-ons with the result. Avoid presenting a promotional starting amount as the complete ongoing cost for a different portfolio.

Match plan scope to responsibilities

A self-managing host may need different reporting from a manager serving several owners. The plan documentation distinguishes features such as owner statements and portals. Identify the actual work and confirm the required access. Software availability does not establish that someone will prepare, review or deliver an accurate owner report for you.

Check a change before applying it

Suppose one property is paused for renovation while another remains active. Ask how that configuration affects the account rather than assuming a single per-night formula. Record the effective date and confirm the next invoice. Keep the support response so a future operator can understand why the expected charge differs from a simple listing count. Also record which listings were merged and why. If the next invoice does not match the expected count, that evidence helps support investigate a concrete configuration rather than a disputed total. Keep any account-specific confirmation with the calculation and revisit it when a property is added, removed or placed back into service.
